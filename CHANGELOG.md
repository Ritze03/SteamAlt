# Changelog

All notable user-facing changes, newest first. Categories:

**Added** (new features),
**Fixed** (bug and behaviour fixes),
**Removed** (things taken out),
**Info** (notes worth knowing).

## 2026-10-25

### Added
- **Easier install**: SteamAlt can now be installed with ritz-get.

### Fixed
- **Title bar**: the logo and name are now centred.

## 2026-10-24

### Added
- **New look**: SteamAlt was rebuilt with a faster, cleaner dark design.
- **Game names**: games show their real names.
- **Account pictures**: accounts show their avatars.
- **Steam folder choice**: pick your Steam folder once and it is remembered.

### Fixed
- **Safer copying**: a failed or cancelled copy no longer damages the existing data.
- **Closing Steam**: works with the Flatpak version of Steam too.
- **Missing game names**: names that failed to load are tried again.

## 2025-12-09

### Fixed
- **Project page**: garbled text on the web page is fixed.

## 2025-04-04

### Added
- **First release**: copy game saves and settings between Steam accounts on the same
  computer.
