SteamAlt is a simple GUI tool that allows you to copy game data (saves, settings, etc.) between different Steam accounts on the same computer.

https://ritze03.github.io/SteamAlt/


### Linux Installation
```bash
ritz-get install SteamAlt
SteamAlt
```

Without ritz-get:
```bash
git clone https://github.com/Ritze03/SteamAlt.git
cd SteamAlt
./install.sh --install
SteamAlt
```

To remove it again: `ritz-get remove SteamAlt` or `./install.sh --remove`.
