SteamAlt is a simple GUI tool that copies game data (saves, settings, etc.) between different Steam accounts on the same computer.

https://ritze03.github.io/SteamAlt/

## Features

- Pick individual games to copy, shown with their real names
- Works on Linux and Windows
- Account avatars as visual confirmation
- Detects a running Steam client and can close it for you
- Safe copy: if a copy fails or is cancelled, the destination's existing data is kept
- Custom Steam folder setting, saved between runs

## Linux Installation
```bash
ritz-get install SteamAlt
SteamAlt
```

Without ritz-get:
```bash
git clone https://github.com/Ritze03/SteamAlt.git
cd SteamAlt
./install.sh --install
SteamAlt
```

To remove it again: `ritz-get remove SteamAlt` or `./install.sh --remove`.

The installer builds from source, so it needs Go, a C compiler and the Gio development headers (see [Building from source](#building-from-source)); if something is missing it lists the packages to install. A prebuilt `SteamAlt-Linux` binary is also attached to the GitHub releases.

## Building from source

SteamAlt is written in Go with the [Gio](https://gioui.org) UI toolkit.

Prerequisites:
- Go 1.27 or newer
- On Linux: a C compiler plus the Wayland/X11/EGL/Vulkan development headers Gio needs, see https://gioui.org/doc/install/linux

Build:
```bash
./build.sh
```

Outputs in `dist/`:
- `dist/SteamAlt-Linux`: native Linux build
- `dist/SteamAlt.exe`: Windows cross-compile (no cgo); the icon is embedded via the committed `rsrc_windows_amd64.syso`, generated by go-winres from `winres/`
